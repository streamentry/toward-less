AGENTOWNERS ตอบคำถามว่า ตามนโยบายที่บันทึกไว้ในรีโพซิทอรี เอเจนต์ AI ทำรายการนี้กับรีโพซิทอรีได้หรือไม่ README อธิบายว่าเป็นเอนจินกฎแบบกำหนดผลแน่นอน ไม่ใช่ผู้รีวิวโค้ดด้วย AI หรือแซนด์บ็อกซ์ขณะรัน

## สิ่งที่ตัดสิน

- อ่านนโยบาย YAML ที่มีเวอร์ชัน ตรวจสัญญาณเอเจนต์ จัดประเภทเส้นทางที่เปลี่ยน และอนุมานการกระทำ
- แก้ข้อขัดแย้งตามลำดับ: บล็อก, ขออนุมัติ, อนุญาต เอเจนต์ที่ไม่รู้จักต้องขออนุมัติโดยปริยาย; การแก้ workflow และไฟล์ลับถูกบล็อกโดยปริยาย
- นโยบายและอินพุตชุดเดิมให้ผลตัดสินเดิม เอนจินไม่เรียกโมเดลหรือ API นโยบายภายนอก

## สิ่งที่ควบคุมไม่ได้

AGENTOWNERS กำกับการมีส่วนร่วมที่ขอบเขตรีโพซิทอรี ไม่ได้ดักการเรียกโมเดลหรือเครื่องมือที่อื่น ไม่ได้แยกการรันโค้ด และไม่ได้ตรวจว่าโค้ดถูกต้องหรือไม่

## สถานะปัจจุบัน

โครงการยังอยู่ก่อนการเปิดตัว: ยังไม่เผยแพร่แพ็กเกจ npm หรือ GitHub Action v0 ที่เสถียร README แนะนำให้ประเมินจากซอร์สและไม่ผูก workflow โปรดักชันไว้กับ main
