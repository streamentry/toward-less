Saigon2Hanoi ฟื้นฟูบล็อกส่วนตัวภาษาเวียดนามให้เป็นเว็บไซต์อ่านแบบสแตติก และบันทึกว่าส่วนใดกู้คืนได้บ้าง

- หน้าแรกใช้ภาพบันทึก Wayback Machine ของ /blog/ เมื่อ 2 กันยายน 2007 ภาพบันทึก root ที่ร้องขอจะเปลี่ยนเส้นทางไป /blog/; ภาพวันที่ 4 กันยายนใช้ตรวจสอบความต่อเนื่อง หน้าแรกมีโพสต์สิบรายการ ลงวันที่ 23 สิงหาคม–1 กันยายน
- คลังเต็มมีบันทึกบทความที่จับเก็บไว้ 68 รายการ แต่ละรายการมีหน้าแยก: 51 รายการมาจากบล็อกปี 2007 และ 17 รายการมาจากการย้ายเว็บไซต์ภายหลัง
- manifest สินทรัพย์บันทึกแหล่งที่มาของภาพและรายการที่ขาดหายไป โดยไม่สร้างภาพประวัติศาสตร์ที่หาไม่พบขึ้นมา

README ระบุว่าเว็บไซต์ไม่ต้อง build และไม่มี runtime dependencies โครงการไม่สร้าง endpoint แบบฟอร์มรับคำรับรอง WordPress เดิมขึ้นใหม่ และแบบฟอร์มไม่ส่งข้อมูล

แหล่งข้อมูล: [ภาพบันทึกบล็อก 2 กันยายน 2007](https://web.archive.org/web/20070902103058id_/http://saigon2hanoi.com:80/blog/), [ARCHIVE.md](https://github.com/streamentry/saigon2hanoi/blob/main/ARCHIVE.md), [manifest สินทรัพย์](https://github.com/streamentry/saigon2hanoi/blob/main/archive/asset-manifest.json) และ [README](https://github.com/streamentry/saigon2hanoi/blob/main/README.md) (อ่านเมื่อ 14 พฤศจิกายน 2026).
