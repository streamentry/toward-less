AI เสนอคำตอบที่เป็นไปได้ได้อย่างรวดเร็ว แต่งานที่ยากกว่าคือการตรวจแหล่งที่มาของข้ออ้าง วิธีการทำซ้ำได้หรือไม่ และผลลัพธ์มีประโยชน์นอกรีโพซิทอรีหรือไม่ [Open Problem Lab](https://github.com/Open-Problem-Lab/open-problem-lab) เป็นโครงการที่ทำงานบน GitHub ซึ่งนักวิจัยและ AI agent แบ่งปัญหาที่ได้รับความสนใจน้อยให้เป็นงานที่มีขอบเขตชัดเจนและตรวจทานได้

ชุดปัญหาแต่ละชุดรวบรวมบันทึกหลักฐาน ชุดข้อมูล แผนผังงาน และเกณฑ์ตรวจสอบไว้ด้วยกัน แผนที่นำทาง agent และดัชนีงานช่วยผู้ร่วมโครงการเลือกงานที่กำหนดขอบเขตชัด การอภิปรายจะกลายเป็น issue ที่มีเงื่อนไขเสร็จสิ้น แล้วพัฒนาเป็น pull request

ก่อนรับผลลัพธ์ โครงการกำหนดให้ตรวจแหล่งข้อมูล ให้ผู้เชี่ยวชาญในสาขาทบทวน และตรวจสอบการทำซ้ำได้ วิธีนี้ช่วยให้ตามรอยแหล่งที่มา วิธีการ และข้อจำกัดของข้ออ้างได้ การตรวจอาจพบข้อผิดพลาด แต่ไม่ได้รับประกันว่าผลจะใช้ได้จริง

รีโพซิทอรีอธิบายชุดปัญหาในมากกว่าสิบสาขา ผู้ร่วมโครงการปรับปรุงแหล่งข้อมูล การตรวจสอบ หรือข้ออ้างได้ทีละรายการ โครงการกำลังสร้างโครงสร้างพื้นฐานให้งานวิจัยผ่านการตรวจทานได้ แต่ไม่ได้รับประกันว่าปัญหาใดได้รับการแก้แล้ว
