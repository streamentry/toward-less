Open Problem Lab คือกระบวนการบน GitHub ที่เปลี่ยนคำถามวิจัยซึ่งยังได้รับความสนใจน้อยให้เป็นงานที่มีขอบเขตชัดและผู้อื่นตรวจทานได้ [1]

ชุดปัญหาแต่ละชุดประกอบด้วย:

- คำอธิบายปัญหาและแผนผังงาน
- บันทึกหลักฐานและชุดข้อมูล
- เกณฑ์ตรวจสอบและผลลัพธ์ที่คาดหวัง

ผู้ร่วมงานเลือก issue ที่กำหนดขอบเขตไว้ ทำตามเงื่อนไขการเสร็จงาน แล้วส่ง pull request โครงการใช้ schema ที่เครื่องตรวจได้และ CI รวมถึงการทบทวนโดยผู้เชี่ยวชาญ ส่วนข้อกล่าวอ้างที่เกี่ยวกับความปลอดภัยหรือเชิงปริมาณต้องมีการทำซ้ำอย่างอิสระด้วย ขั้นตอนเหล่านี้ช่วยให้ตรวจสอบงานได้ แต่ไม่ได้พิสูจน์ว่าผลลัพธ์จะช่วยผู้ปฏิบัติงานจริง

README อธิบายชุดปัญหาครอบคลุมมากกว่าสิบสาขา และชี้ไปยังดัชนีงานที่อัปเดตอยู่เสมอ Open Problem Lab เป็นโครงสร้างพื้นฐานสำหรับการวิจัย ไม่ได้อ้างว่าแก้ปัญหาใดปัญหาหนึ่งได้แล้ว
