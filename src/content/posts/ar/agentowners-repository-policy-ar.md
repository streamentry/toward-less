يجيب AGENTOWNERS عن سؤال واحد: وفق السياسة المحفوظة في المستودع، هل يجوز لوكيل ذكاء اصطناعي تنفيذ هذا الإجراء فيه؟ يصفه README بأنه محرك قواعد حتمي، لا مراجعًا للشفرة بالذكاء الاصطناعي ولا بيئة عزل وقت التشغيل.

## ما الذي يقرره؟

- يقرأ سياسة YAML ذات إصدار، ويرصد إشارات الوكلاء، ويصنف المسارات المتغيرة، ويستنتج الإجراءات.
- يحل التعارض بهذا الترتيب: حظر، طلب موافقة، سماح. تتطلب الوكلاء غير المعروفة موافقة افتراضيًا؛ وتُحظر تغييرات ملفات سير العمل والأسرار.
- تنتج السياسة والمدخلات نفسها الحكم نفسه. لا يستدعي المحرك نموذجًا ولا واجهة سياسة مستضافة.

## ما الذي لا يستطيع التحكم فيه؟

ينظم AGENTOWNERS المساهمات عند حدود المستودع. ولا يعترض استدعاءات النماذج أو الأدوات في مواضع أخرى، ولا يعزل تنفيذ الشفرة، ولا يحكم على صحتها.

## الحالة الحالية

المشروع قبل الإصدار: لم تُنشر حزم npm ولا GitHub Action مستقرة بإصدار v0. يوصي README بالتقييم من المصدر، وعدم تثبيت سير عمل الإنتاج على main.
