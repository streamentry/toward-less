Open Problem Lab هو مسار عمل على GitHub يحوّل الأسئلة البحثية التي لم تحظَ باهتمام كافٍ إلى مهام محددة يمكن للآخرين مراجعتها. [1]

تتضمن حزمة المشكلة:

- بيان المشكلة وخريطة المهام؛
- سجلات الأدلة ومجموعات البيانات؛
- معايير التحقق والمخرجات المتوقعة.

يختار المساهم issue محدد النطاق، وينجز شرطه، ثم يرسل pull request. يستخدم المستودع مخططات قابلة للتحقق آليًا وCI ومراجعة خبراء المجال. أما الادعاءات الحساسة للسلامة أو الكمية فتتطلب إعادة تحقق مستقلة. تسهّل هذه الفحوص التدقيق، لكنها لا تثبت أن النتيجة ستفيد الممارسين.

يصف README حزمًا في أكثر من عشرة مجالات، ويشير إلى فهارس مهام تتغير باستمرار. Open Problem Lab بنية تحتية للبحث، ولا يدّعي أنه حل مشكلة بعينها.
