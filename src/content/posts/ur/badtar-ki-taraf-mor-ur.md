یہ مضمون David Gilmore کے 9 نومبر کے لانچ اعلان کا موازنہ 11 نومبر 2026 تک Rayline کی سرکاری سائٹ پر موجود معلومات سے کرتا ہے۔

Gilmore نے لکھا: “On Wednesday, we’re launching Rayline.” (بدھ کو ہم Rayline لانچ کر رہے ہیں۔) پوسٹ میں صحت کی ٹیکنالوجی پر ان کے کام اور اخلاقی فیصلوں کا ذاتی بیان بھی ہے، ساتھ ہی کمپنی کے 8.5 ملین ڈالر اکٹھے کرنے کا دعویٰ۔ یہ بانی کے اپنے بیانات ہیں۔

## سرکاری صفحات پر اب کیا ہے

Rayline چار مصنوعات دکھاتا ہے:

- **ARC** ماڈل اور reasoning کی سطح چنتا ہے۔ Responses API تیار جواب دے سکتی ہے؛ Routes API ماڈل کی تجویز دیتی ہے تاکہ صارف اپنے نظام میں inference چلائے۔
- **Decisions API** منظم صورت میں اختیارات، امکانات اور اسکور دیتی ہے۔
- **Raydock** ایک open-source کمانڈ لائن ٹول ہے جو agent tools کو مقامی اور cloud ماڈلز سے جوڑتا ہے۔
- **Workshop** cloud یا desktop پر ایپس اور دوسرے سافٹ ویئر بنانے کے لیے ہے۔

ان صفحات میں hosted خدمات اور مقامی open-source اوزار دونوں شامل ہیں۔ “وکندریقرت” Gilmore کی اپنی تعبیر ہے؛ درج مصنوعات ایک مخلوط نظام ہیں، مکمل طور پر وکندریقرت نہیں۔ Rayline کی سائٹ اپنے معیار اور لاگت کے اعداد بھی دکھاتی ہے اور ایک تکنیکی رپورٹ سے جوڑتی ہے۔ اس مضمون میں ان نتائج کا آزادانہ جائزہ نہیں لیا گیا۔

## کون سی باتیں اب بھی بانی کا بیان ہیں

پہلے کے healthcare AI کام، مالی پیشکش ٹھکرانے اور 8.5 ملین ڈالر جمع کرنے کی تفصیل Gilmore کی اپنی کہانی ہے۔ مصنوعات کے صفحات Rayline کی عوامی پیشکش دکھاتے ہیں، مگر ذاتی تاریخ، فنڈنگ، ہسپتالوں میں استعمال یا صارفین کے نتائج کی تصدیق نہیں کرتے۔

11 نومبر تک لانچ محض وعدہ نہیں رہا: Rayline کی مصنوعات کے صفحات عوامی ہیں۔ اس سے مصنوعات کے مجموعے کا وجود ثابت ہوتا ہے، ان کی کارکردگی یا اثر کا آزادانہ ثبوت نہیں۔
