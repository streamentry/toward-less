Open Problem Lab ایک GitHub طریقۂ کار ہے جو کم توجہ پانے والے تحقیقی سوالات کو ایسے محدود کاموں میں بدلتا ہے جن کا دوسرے لوگ جائزہ لے سکیں۔ [1]

ہر مسئلہ پیک میں یہ چیزیں ہوتی ہیں:

- مسئلے کا بیان اور کاموں کا نقشہ؛
- شواہد کے ریکارڈ اور ڈیٹاسیٹ؛
- توثیق کے معیار اور متوقع نتائج۔

حصہ لینے والا محدود دائرے والا issue چنتا ہے، اس کی تکمیل کی شرط پوری کرتا ہے، پھر pull request بھیجتا ہے۔ ریپوزٹری مشین سے جانچے جانے والے schemas اور CI، شعبے کے ماہرین کا جائزہ، اور حفاظت سے متعلق یا مقداری دعووں کے لیے آزادانہ تکرار استعمال کرتی ہے۔ یہ جانچ پڑتال کام کو audit کرنا آسان بناتی ہے، مگر یہ ثابت نہیں کرتی کہ نتیجہ عملی میدان میں مددگار ہوگا۔

README دس سے زیادہ شعبوں کے مسئلہ پیک بیان کرتا ہے اور مسلسل بدلتے کاموں کی فہرستوں سے جوڑتا ہے۔ Open Problem Lab تحقیق کا بنیادی ڈھانچہ ہے؛ یہ دعویٰ نہیں کرتا کہ کوئی خاص مسئلہ حل ہو چکا ہے۔
