Open Problem Lab은 충분히 다뤄지지 않은 연구 질문을 다른 사람이 검토할 수 있는 범위의 작업으로 바꾸는 GitHub 기반 절차입니다. [1]

각 문제 팩에는 다음이 들어 있습니다.

- 문제 설명과 작업 지도
- 근거 기록과 데이터셋
- 검증 기준과 예상 산출물

기여자는 범위가 정해진 issue를 고르고 완료 조건에 맞춰 작업한 뒤 pull request를 제출합니다. 저장소는 기계가 확인할 수 있는 스키마와 CI, 분야 전문가 검토를 사용합니다. 안전에 민감하거나 정량적인 주장에는 독립 재현도 요구합니다. 이런 검사는 감사를 쉽게 하지만 결과가 현장 실무에 도움이 된다는 사실까지 증명하지는 않습니다.

README는 10개가 넘는 분야의 문제 팩과 계속 바뀌는 작업 목록을 안내합니다. Open Problem Lab은 연구 기반 시설이며, 특정 문제를 이미 해결했다고 주장하지 않습니다.
