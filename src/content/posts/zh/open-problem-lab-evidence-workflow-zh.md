Open Problem Lab 是一个基于 GitHub 的工作流程，把尚未充分解决的研究问题拆成有明确范围、可供他人审查的任务。[1]

每个问题包包含：

- 问题陈述和任务地图；
- 证据记录和数据集；
- 验证标准和预期产出。

贡献者选择一个范围明确的 issue，按其完成条件开展工作，再提交 pull request。仓库使用可机读的 schema 和 CI，并设置领域评审；涉及安全或定量结论时还要求独立复现。这些检查让工作更容易审计，但不能证明结果一定能帮助一线实践者。

README 介绍了覆盖十多个领域的问题包，并指向会持续变化的实时任务索引。Open Problem Lab 是研究基础设施，不声称任何具体问题已经解决。
