OpenAMP Foundry pergunta: pontuações transparentes podem organizar candidatos a peptídeos antimicrobianos (AMP) para avaliação especializada? O repositório atual é uma demo dry lab; não comprova atividade biológica de nenhum candidato.

A demo usa dados de exemplo e pontuações-base transparentes para avaliar:

- potencial de atividade;
- risco de segurança;
- viabilidade;
- novidade.

Ela gera classificações e registros de evidências para revisão humana. O repositório não oferece instruções biológicas operacionais. Ensaios laboratoriais continuam necessários antes de afirmar atividade. A meta de longo prazo — ajudar cientistas qualificados a escolher experimentos e aprender com os resultados — ainda não foi demonstrada pelo software atual.
