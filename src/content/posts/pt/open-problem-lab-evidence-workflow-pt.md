A IA pode sugerir respostas candidatas com rapidez. O trabalho difícil é verificar as fontes das afirmações, a possibilidade de reproduzir os métodos e a utilidade fora do repositório. [Open Problem Lab](https://github.com/Open-Problem-Lab/open-problem-lab) é um projeto baseado no GitHub em que pesquisadores e agentes de IA transformam problemas negligenciados em tarefas delimitadas e revisáveis.

Cada pacote de problema reúne registros de evidências, conjuntos de dados, um mapa de tarefas e critérios de validação. O radar de agentes e o índice de tarefas ajudam quem contribui a encontrar um trabalho definido. Uma discussão vira uma issue com condição de conclusão e depois uma pull request.

Antes de aceitar um resultado, o projeto exige checagem das fontes, revisão de especialistas e verificação de reprodutibilidade. Isso facilita rastrear as fontes, os métodos e os limites das afirmações. As verificações podem encontrar erros; não garantem que um resultado seja útil na prática.

O repositório descreve pacotes de problemas em mais de dez áreas. É possível melhorar uma fonte, verificação ou afirmação por vez. O projeto constrói uma infraestrutura para pesquisas que resistam à revisão, sem garantir que algum problema já tenha sido resolvido.

[Leia o README do projeto](https://github.com/Open-Problem-Lab/open-problem-lab).
