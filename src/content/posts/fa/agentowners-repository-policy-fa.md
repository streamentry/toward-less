AGENTOWNERS به این پرسش پاسخ می‌دهد: طبق سیاست ثبت‌شده در مخزن، عامل هوش مصنوعی اجازه دارد این کار را در مخزن انجام دهد؟ README آن را یک موتور قواعد قطعی معرفی می‌کند، نه بازبین کد هوش مصنوعی یا محیط ایزولهٔ زمان اجرا.

## چه چیزی را تعیین می‌کند

- سیاست YAML نسخه‌دار را می‌خواند، نشانه‌های عامل را تشخیص می‌دهد، مسیرهای تغییریافته را دسته‌بندی و کارها را استنباط می‌کند.
- تعارض را به این ترتیب حل می‌کند: مسدودکردن، درخواست تأیید، اجازه‌دادن. عامل ناشناخته به‌طور پیش‌فرض به تأیید نیاز دارد؛ تغییر workflow و فایل‌های محرمانه به‌طور پیش‌فرض مسدود است.
- سیاست و ورودی یکسان همیشه به یک حکم می‌رسند. موتور به مدل یا API میزبانی‌شدهٔ سیاست فراخوانی نمی‌زند.

## چه چیزی را کنترل نمی‌کند

AGENTOWNERS مشارکت‌ها را در مرز مخزن مدیریت می‌کند. فراخوانی مدل یا ابزار را در جای دیگر متوقف نمی‌کند، اجرای کد را ایزوله نمی‌کند و درستی کد را نمی‌سنجد.

## وضعیت فعلی

پروژه هنوز پیش از انتشار است: بسته‌های npm و GitHub Action پایدار v0 منتشر نشده‌اند. README می‌گوید از روی کد ارزیابی کنید و workflow تولیدی را روی main ثابت نکنید.
