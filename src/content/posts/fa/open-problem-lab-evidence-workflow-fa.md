Open Problem Lab فرایندی در GitHub است که پرسش‌های پژوهشی کم‌بررسی‌شده را به وظایف محدود و قابل بازبینی برای دیگران تبدیل می‌کند. [1]

هر بستهٔ مسئله شامل این موارد است:

- شرح مسئله و نقشهٔ وظایف؛
- سوابق شواهد و مجموعه‌داده‌ها؛
- معیارهای اعتبارسنجی و خروجی‌های مورد انتظار.

مشارکت‌کننده یک issue با دامنهٔ مشخص برمی‌دارد، شرط پایان آن را انجام می‌دهد و pull request می‌فرستد. مخزن از schemaهای قابل بررسی با ماشین و CI، بازبینی متخصصان حوزه، و برای ادعاهای حساس به ایمنی یا کمی، بازتولید مستقل استفاده می‌کند. این بررسی‌ها ممیزی را آسان‌تر می‌کنند، اما ثابت نمی‌کنند که نتیجه در عمل به متخصصان کمک خواهد کرد.

README بسته‌هایی را در بیش از ده حوزه توصیف می‌کند و به فهرست‌های زندهٔ وظایف پیوند می‌دهد که مرتب تغییر می‌کنند. Open Problem Lab زیرساخت پژوهش است و ادعا نمی‌کند مسئلهٔ مشخصی را حل کرده باشد.
