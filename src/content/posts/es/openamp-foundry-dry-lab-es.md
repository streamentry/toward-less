OpenAMP Foundry plantea esta pregunta: ¿pueden unas puntuaciones transparentes ordenar candidatos a péptidos antimicrobianos (AMP) para que los revisen especialistas? El repositorio actual es una demo dry lab; no demuestra que ningún candidato tenga actividad biológica.

La demo usa datos de ejemplo y puntuaciones base transparentes para evaluar:

- potencial de actividad;
- riesgo para la seguridad;
- viabilidad;
- novedad.

Genera clasificaciones y registros de evidencia para revisión humana. El repositorio no ofrece instrucciones biológicas operativas. Para afirmar que un péptido tiene actividad siguen haciendo falta ensayos de laboratorio. La meta a largo plazo —ayudar a científicos cualificados a elegir experimentos y aprender de sus resultados— aún no está demostrada por el software actual.
