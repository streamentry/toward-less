Buddhist Textual Witnesses est un catalogue aligné sur les sources pour comparer les textes bouddhiques sans considérer les passages parallèles comme des copies d’un original unique qu’on pourrait reconstituer.

Le catalogue consigne les œuvres, les langues, les témoins textuels et les révisions exactes des sources pour :

- le sanskrit, le sanskrit hybride bouddhique et le prâkrit/gāndhārī ;
- les témoins en chinois classique ;
- le pāli comme base d’alignement lorsque c’est utile, et non comme origine de toutes les traditions.

Le projet distingue manuscrits, éditions, traductions et reconstructions. Ses tableaux de correspondance suivent trois règles :

- un parallèle textuel complet n’est pas forcément exact ;
- les rapprochements générés par machine restent des candidats jusqu’à une revue humaine et une promotion explicite ;
- les sources dont les droits de redistribution sont incertains peuvent être enregistrées sans être copiées dans le dépôt.

C’est une infrastructure de comparaison, pas l’affirmation qu’un canon bouddhique original unique aurait été reconstitué.
