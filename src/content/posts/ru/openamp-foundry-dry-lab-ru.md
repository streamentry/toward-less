OpenAMP Foundry проверяет, могут ли прозрачные оценки упорядочить кандидаты антимикробных пептидов (AMP) для экспертной проверки. Текущий репозиторий — это dry-lab-демо, а не доказательство биологической активности какого-либо кандидата.

Демо использует учебные данные и прозрачные базовые оценки для следующих характеристик:

- вероятность активности;
- риск для безопасности;
- реализуемость;
- новизна.

Система формирует рейтинг и записи доказательств для проверки человеком. В репозитории нет практических биологических инструкций. Для утверждения об активности нужны лабораторные испытания. Долгосрочная цель — помочь квалифицированным учёным выбирать эксперименты и учиться на результатах — текущим ПО ещё не продемонстрирована.
