AGENTOWNERS отвечает на вопрос: разрешает ли политика в репозитории выполнить это действие ИИ-агенту? README описывает его как детерминированный механизм правил, а не ИИ-ревьюера или песочницу времени выполнения.

## Что он решает

- Читает версионируемую политику YAML, распознаёт сигналы агента, классифицирует изменённые пути и определяет действия.
- Разрешает конфликты в порядке: заблокировать, запросить одобрение, разрешить. Неизвестным агентам по умолчанию нужно одобрение; изменения workflow и файлов секретов блокируются.
- Одна политика и одинаковые входные данные дают один вердикт. Механизм не вызывает модель или размещённый API политик.

## Чего он не контролирует

AGENTOWNERS регулирует вклад на границе репозитория. Он не перехватывает вызовы моделей и инструментов за её пределами, не изолирует выполнение кода и не оценивает его корректность.

## Текущий статус

Проект ещё не выпущен: npm-пакеты и стабильный GitHub Action v0 не опубликованы. README советует оценивать исходный код и не закреплять main в рабочем процессе продакшена.
