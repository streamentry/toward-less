Open Problem Lab हा GitHub वरील कार्यप्रवाह आहे. तो कमी लक्ष मिळालेल्या संशोधन प्रश्नांना इतरांनी तपासता येतील अशा मर्यादित कामांत रूपांतरित करतो. [1]

प्रत्येक problem pack मध्ये असते:

- समस्येचे विधान आणि कामांचा नकाशा;
- पुराव्याच्या नोंदी आणि डेटासेट;
- पडताळणीचे निकष आणि अपेक्षित निष्पन्न.

योगदानकर्ते स्पष्ट व्याप्तीचा issue निवडतात, त्याची पूर्णत्वाची अट पूर्ण करतात आणि pull request पाठवतात. रेपॉझिटरीमध्ये मशीनने तपासता येणारे schema आणि CI, विषयतज्ज्ञांचे पुनरावलोकन, तसेच सुरक्षिततेशी संबंधित किंवा संख्यात्मक दाव्यांसाठी स्वतंत्र पुनरुत्पादन आहे. या तपासण्यांमुळे audit सोपे होते; परिणाम प्रत्यक्ष कामात उपयोगी पडेल हे सिद्ध होत नाही.

README दहापेक्षा अधिक क्षेत्रांतील problem packs वर्णन करते आणि सतत बदलणाऱ्या कामांच्या निर्देशांकांकडे निर्देश करते. Open Problem Lab हे संशोधनाचे पायाभूत साधन आहे; एखादी विशिष्ट समस्या सुटली आहे असा दावा करत नाही.
